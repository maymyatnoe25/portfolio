# May Myat Noe Lwin — Portfolio

React + TypeScript + Vite + Framer Motion. Content lives in `src/data.ts`; styles in `src/index.css`.

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

## Push to GitHub
    git init && git add . && git commit -m "Initial portfolio"
    git branch -M main
    git remote add origin https://github.com/maymyatnoe25/portfolio.git
    git push -u origin main

Then in the repo: Settings → Pages → Source: GitHub Actions. The workflow deploys on every push to `main`.
